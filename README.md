# zapret-auto

Автоматическая настройка [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (Flowseal) для Windows:

- сама скачивает и обновляет zapret в `C:\zapret`, сохраняя ваши списки;
- подбирает стратегию (`general*.bat`), при которой открываются YouTube, Discord и **ваши сайты**, и ставит её службой Windows;
- при включении ПК тихо (без окон) проверяет, что всё работает, и перебирает стратегии, только если что-то перестало открываться;
- если её прервать посреди работы, сама возвращает прежнюю службу.

Новые стратегии из обновлений Flowseal подхватываются автоматически: программа берёт все `general*.bat`, сколько бы их ни было.

## Установка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте в любую папку.
2. Если стоит другой обход блокировок (другой zapret, GoodbyeDPI) — удалите его.
3. Если включён VPN в режиме TUN — выключите его на время настройки (иначе проверки пройдут при любой стратегии).
4. Дважды щёлкните **`2. Починить (обновить и подобрать).cmd`**, ответьте «Да». Подождите 1–3 минуты, интернет может мигать. Не закрывайте окно.
5. Дважды щёлкните **`4. Включить автозапуск.cmd`**, ответьте «Да».

Нужна Windows 10 (1803+) или 11 — `curl.exe` и PowerShell 5.1 там уже есть.

## Кнопки

| Файл | Что делает |
|---|---|
| `1. Проверить, что всё работает` | Показывает, что открывается. Ничего не меняет |
| `2. Починить (обновить и подобрать)` | Обновляет zapret, если вышла новая версия; подбирает стратегию, если что-то не открывается |
| `3. Подобрать стратегию заново` | Принудительный перебор стратегий |
| `4. Включить автозапуск` | Скрытая проверка через 2 мин после включения ПК (задача Планировщика от SYSTEM) |
| `5. Выключить автозапуск` | Убирает автопроверку, zapret продолжает работать |
| `6. Открыть лог` | Что программа делала: `C:\zapret-auto\zapret-auto.log` |
| `7. Мои сайты` | Свои сайты, которые должны открываться |
| `8. Исключения` | Сайты и IP, которые zapret не должен трогать |

## Мои сайты и исключения

Кнопки 7 и 8 открывают список в Блокноте. Впишите домены по одному в строке (можно вставить ссылку целиком — домен вытащится сам), сохраните (Ctrl+S), закройте Блокнот и нажмите Enter в синем окне.

- **Мои сайты** попадают в `list-general-user.txt` zapret и участвуют в проверках: стратегия подбирается так, чтобы открывались и они.
- **Исключения** попадают в `list-exclude-user.txt` (домены) и `ipset-exclude-user.txt` (IP и подсети, например `10.0.0.0/8`). Если сайт есть в обоих списках, побеждает исключение.
- Чтобы убрать сайт — удалите строку и сделайте то же самое. Строки, которые вы вписали в файлы zapret вручную, программа не трогает.

Добавляйте в «Мои сайты» только то, что блокируется через DPI. Если сайт не работает по другой причине (лежит или заблокирован по IP), программа при каждом включении ПК будет перебирать стратегии впустую.

## Как выбирается стратегия

Проверка идёт мимо системного прокси (`curl --noproxy`), чтобы оценивался именно zapret. Сначала проверяется текущая стратегия, затем остальные по порядку; первая, при которой открывается всё, сразу ставится. Если такой нет — ставится лучшая. Стратегия, после которой не открывается `ya.ru`, не выбирается никогда: она ломает обычный интернет.

## Настройки

В начале `zapret-auto.ps1`:

- `$ExtraDomains` — домены, которые всегда добавляются в список zapret;
- `$GameProcesses` — процессы, при которых программа ничего не трогает (например `@('cs2')`), чтобы не оборвать игру;
- `$Targets` — какие адреса проверяются.

После правки скрипта запустите `4. Включить автозапуск` ещё раз: задача использует копию из `C:\zapret-auto\`.

## Если что-то не так

- Антивирус удалил `winws.exe` / `WinDivert` — добавьте `C:\zapret` в исключения.
- Смотрите лог (кнопка 6): там результат каждой стратегии.
